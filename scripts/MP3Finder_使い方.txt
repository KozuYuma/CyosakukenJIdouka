========================================
 NUENDO MP3 Finder ― 使い方
========================================

NUENDO の Cue CSV に書かれた曲（イベント名）と、
手元のフォルダにある MP3 ファイルを突き合わせて、
再生時間やID3タグ（曲名・アーティスト・アルバム・作曲者）を
CSV にまとめるツールです。

Python のインストールは不要です。
NUENDO_MP3_Finder.exe を、この使い方メモと一緒に
好きな場所（デスクトップなど）に置いてください。


----------------------------------------
 使い方
----------------------------------------

1. NUENDO_MP3_Finder.exe をダブルクリックします。

2. 「Cue CSV」の[参照...]を押して、
   NUENDO から書き出した Cue の CSV を選びます。

3. 「MP3 フォルダ」の[参照...]を押して、
   MP3 が入っているフォルダを選びます。
   → フォルダの中のサブフォルダも自動で探します。

4. 「出力先 CSV」は、2. で CSV を選んだ時点で自動的に入ります。
   変えたいときだけ[参照...]で選び直してください。

5. [実 行]を押します。

6. 「完了しました」と出たら終わりです。
   [出力先を開く]を押すと、できた CSV の場所が開きます。

できた CSV は Excel でそのまま開けます。


----------------------------------------
 「部分一致も含める」について
----------------------------------------

チェックを入れると、曲名の一部が一致するファイルも拾います（初期設定はオン）。

  入れる  … 取りこぼしが減るが、関係ないファイルも混ざることがある
  はずす  … 確実なものだけ。件数は減る

まず初期設定のまま実行して、余計なものが多ければ外してみてください。
CSV の「マッチ種別」列に、どれくらい確実な一致かが書いてあります。

  完全一致    … ファイル名がイベント名とそのまま同じ（いちばん確実）
  正規化一致  … 全角/半角・記号の違いを無視すると同じ
  管理番号一致… 管理番号（例 7ST-042-22）が同じ
  タイトル一致… 番号などを取り除いた曲名部分が同じ
  部分一致    … 曲名の一部が同じ（確認推奨）
  該当なし    … 見つからなかった


----------------------------------------
 うまくいかないとき
----------------------------------------

■「CSV からイベント名を取得できませんでした」と出る
  → NUENDO の Cue CSV ではない可能性があります。
     「イベント名」「ファイル名」という列がある CSV か確認してください。

■ 該当なしばかりになる
  → MP3 フォルダの指定が違っているか、
     ファイル名がイベント名と大きく違う可能性があります。
     「部分一致も含める」にチェックが入っているか確認してください。

■ Windows に「発行元不明」と警告される
  → 署名を付けていないため出ます。
     「詳細情報」→「実行」で起動できます。

■ 起動に数秒かかる
  → 1つのファイルにまとめてある exe のため、
     初回は展開に少し時間がかかります。異常ではありません。


----------------------------------------
 出力される CSV の列
----------------------------------------

イベント名 / マッチ種別 / ファイル名 / フルパス /
ファイルサイズ / 更新日時 / 再生時間 /
ビットレート / サンプルレート / チャンネル数 /
タイトル(ID3) / アーティスト(ID3) / アルバム(ID3) / 作曲者(ID3) /
ジャンル(ID3) / 年(ID3) / トラック(ID3) / コメント(ID3)
